# DB-backed System Prompts + Admin Editor — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let admins view/edit any system prompt from the admin panel, taking effect live with no redeploy — global, edit-in-place, reset-to-shipped-default, confirm-on-save, with required-placeholder validation.

**Architecture:** A `prompts` table (one row per overridden `kind`) overrides the shipped `backend/prompts/<kind>.md` files. `load_prompt(kind)` stays **synchronous**, reading a bustable in-process cache (`_CACHE`) that a new `PromptService.refresh_cache()` primes from the DB at lifespan startup and after every admin save/reset — so no `load_prompt` call site changes. A `/api/admin/prompts` router (admin-only) drives an admin2 "System prompts" page.

**Tech Stack:** FastAPI (Python 3.13, uv) + SQLAlchemy async + Alembic; React 18 / Vite / @tanstack/react-query / openapi-fetch.

## Task 2: `PromptRepository`

**Files:** Create `backend/src/repositories/prompt_repository.py`.

**Interfaces — Produces:**
- `PromptRepository(session: AsyncSession)`
- `async list_all() -> list[Prompt]`
- `async get(kind: str) -> Prompt | None`
- `async upsert(kind: str, content: str, updated_by: uuid.UUID | None) -> None`
- `async delete(kind: str) -> None`

- [ ] **Step 1:** Implement, mirroring `conversation_repository.py`'s style (constructor takes `_session`, uses `select`/`update`/`insert ... on_conflict_do_update`, `await self._session.commit()`):
```python
from __future__ import annotations
import uuid
from typing import Any
from sqlalchemy import delete as sa_delete, select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.ext.asyncio import AsyncSession
from src.db.models.prompt import Prompt

class PromptRepository:
    def __init__(self, session: AsyncSession) -> None:
        self._session = session

    async def list_all(self) -> list[Prompt]:
        result = await self._session.execute(select(Prompt))
        return list(result.scalars().all())

    async def get(self, kind: str) -> Prompt | None:
        return await self._session.get(Prompt, kind)

    async def upsert(self, kind: str, content: str, updated_by: uuid.UUID | None) -> None:
        values: dict[str, Any] = {"kind": kind, "content": content, "updated_by": updated_by}
        stmt = pg_insert(Prompt).values(**values).on_conflict_do_update(
            index_elements=[Prompt.kind],
            set_={"content": content, "updated_by": updated_by},
        )
        await self._session.execute(stmt)
        await self._session.commit()

    async def delete(self, kind: str) -> None:
        await self._session.execute(sa_delete(Prompt).where(Prompt.kind == kind))
        await self._session.commit()
```

```python
from __future__ import annotations
from pathlib import Path

__all__ = ["load_prompt", "read_file", "set_cache", "reset_cache", "clear_cache"]

_PROMPTS_DIR = Path(__file__).resolve().parents[2] / "prompts"
_CACHE: dict[str, str] = {}

def read_file(kind: str) -> str:
    """The shipped default for `kind` (ignores overrides)."""
    return (_PROMPTS_DIR / f"{kind}.md").read_text(encoding="utf-8").strip()

def load_prompt(kind: str) -> str:
    """Active prompt: an admin DB override once primed into the cache (see
    PromptService.refresh_cache — lifespan startup + every save/reset), else the file."""
    cached = _CACHE.get(kind)
    if cached is not None:
        return cached
    text = read_file(kind)
    _CACHE[kind] = text
    return text

def set_cache(kind: str, content: str) -> None:
    _CACHE[kind] = content

def reset_cache(kind: str) -> None:
    _CACHE.pop(kind, None)

def clear_cache() -> None:
    _CACHE.clear()
```
