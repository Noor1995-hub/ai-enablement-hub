## Model Context Protocol: Advanced Topics
**URL:** https://anthropic.skilljar.com/model-context-protocol-advanced-topics
**Description:** Advanced MCP implementation patterns — server-client communication, transport mechanisms, production deployment. Sampling, notifications, filesystem access control, transport protocol internals.
**Learning objectives:**
- Sampling: how MCP servers request LLM calls through connected clients (shifts AI cost from server to client)
- Notification systems: context objects, logging callbacks, progress reporting
- Roots-based file access: permission systems for specific directories with security boundaries
- JSON message architecture: request-result pairs vs. notification messages
- Stdio transport: client-server comms via stdio streams, initialization handshake
- StreamableHTTP transport: SSE enabling server-to-client HTTP comms, session management
- HTTP transport limitations and configuration flag impacts
- Production scaling: stateless HTTP for horizontal scaling with load balancers
- Transport selection criteria based on deployment requirements
**Prerequisites:** Python with async programming; familiarity with JSON/HTTP; basic SSE knowledge.
